# Debug Logging

Potion of Resurrection exposes a `Debug Logging` setting on its MSU General page. It defaults to enabled for development.

When enabled, diagnostic messages are written to:

`C:\Users\gujar\Documents\Battle Brothers\log.html`

Disable the setting to suppress `[PotionResurrection]` diagnostic output without changing resurrection behavior. Re-enable it before investigating potion availability or resurrection failures.
